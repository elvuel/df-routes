# routes

该目录现在采用“按地图分层”的主结构：

- `zero_dam/`：当前零号大坝主路线目录；
- `<future_map>/`：后续其它地图的路线目录；
- 根目录现有 `.json`、`share/`、`spikes/`、`test/` 先保留为 legacy 内容。

当前运行时行为：

1. 若存在 `routes/<current_map_id>/`，则路线列表优先只读取该地图子目录；
2. 解析具体路线文件时，先查 `routes/<current_map_id>/...`；
3. 若当前地图子目录中不存在该文件，再回退到 `routes/...` 根目录兼容旧引用。

这意味着：

- 新路线应优先放到对应地图子目录；
- 旧路线暂时无需立即删除或改名；
- 根目录 legacy 内容后续可分阶段继续迁移清理。
