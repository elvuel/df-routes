# routes

当前仓库按地图分目录组织路线文件。

## 目录结构

- `zero_dam/`：零号大坝路线目录
- `<future_map>/`：后续新增地图时按同级目录扩展

## 当前状态

- 根目录只保留地图级目录与仓库说明文件
- `example_map/`、`original/` 等历史目录已移除
- 各地图目录内按需要维护路线 `.json`、`share/`、`spikes/`、`test/` 等子目录

## 维护约定

- 新路线优先放到对应地图目录下
- 地图内公共片段放在该地图自己的 `share/` 目录
- 删除共享片段前，先确认没有被入口路线递归 `import`
